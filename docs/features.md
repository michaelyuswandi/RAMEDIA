# RAMEDIA Features

## 🎵 Song Lyrics Display

### Smart Import

- **Paste & Parse** - Paste lyrics, system auto-detects sections
- **Double-Enter Split** - Press Enter twice to create new slide
- **Section Detection** - Auto-detect Verse, Chorus, Bridge, etc.
- **Batch Import** - Import multiple songs from text files

### Display Options

- **Typography Control** - Font family, size, weight, shadow
- **Text Positioning** - Top, center, bottom alignment
- **Line Spacing** - Adjustable line height
- **Word Highlighting** - Highlight current line (karaoke mode)

### Customization Per Song

- **Custom Background** - Override default theme per song
- **Custom Styling** - Per-song text styling
- **Verse Order** - Rearrange verses for service

---

## 📖 Bible Presentation

### Verse Display

- **Quick Search** - Type "John 3:16" to find instantly
- **Range Selection** - Display multiple verses (John 3:16-18)
- **Split Display** - Show verse reference + text on same slide

### Multiple Translations

- **Default Support** - Indonesian TB, English NIV/ESV/KJV
- **Side-by-Side** - Show two translations simultaneously
- **Easy Switch** - Change translation on-the-fly

## 🖼️ Media & Backgrounds

### Supported Formats

| Type   | Formats             |
| ------ | ------------------- |
| Images | JPG, PNG, WebP, GIF |
| Videos | MP4, WebM, MOV      |
| Audio  | MP3, WAV, OGG       |

### Background Options

- **Solid Colors** - Color picker with presets
- **Gradients** - Linear, radial with multiple stops
- **Images** - Static or slideshow
- **Videos** - Looping video backgrounds
- **Motion** - Animated particle effects

### Media Library

- **Organized Folders** - Categories for easy access
- **Drag & Drop Import** - Quick media import
- **Preview Thumbnails** - Visual media browser
- **Search** - Find media by name

---

## 📑 Layer System

### Layer Types

1. **Background Layer** (z-100) - Base visual
2. **Media Layer** (z-200) - Images, videos, PDF slides
3. **Overlay Layer** (z-300) - Logos, lower thirds
4. **Text Layer** (z-400) - Lyrics, scripture, announcements

### Layer Controls

- **Visibility Toggle** - Show/hide layers
- **Opacity Control** - Adjust transparency
- **Position & Scale** - Move and resize
- **Transitions** - Fade, slide, zoom effects

---

## 📋 Schedule / Service Rundown

### Planning

- **Service Builder** - Drag items to create service order
- **Time Estimation** - Set duration per item
- **Notes** - Add operator notes per item

### Execution

- **One-Click Next** - Advance to next item
- **Skip/Reorder** - Adjust during service
- **Loop Item** - Keep current item repeating

## 🖥️ Multi-Output Display

### Display Detection

- **Auto-Detect** - Find all connected displays
- **Monitor Preview** - See display arrangement
- **Assign Output** - Choose which display for output

### Output Modes

- **Fullscreen** - Standard projection mode
- **Stage Display** - Clock + next verse for worship team
- **Confidence Monitor** - Presenter notes view

---

## 🎥 Live Capture / Screen Share

### Capture Sources

- **Screen Share** - Send a selected screen or app window to the output
- **HDMI Input** - Future support for capture cards exposed as video devices
- **Camera Input** - Future support for USB cameras or virtual camera sources

### Output Behavior

- **Live Source Mode** - Capture behaves as temporary live output, not media library content
- **Stop Capture** - Return cleanly to the normal slide output flow
- **Black / Clear Support** - Existing output safety controls still apply

See [Capture / Screen Share Module](capture-screen-share-module.md) for the technical plan.
